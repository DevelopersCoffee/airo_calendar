# `airo_calendar`

[![pub package](https://img.shields.io/pub/v/airo_calendar.svg)](https://pub.dev/packages/airo_calendar)
[![CI](https://github.com/DevelopersCoffee/airo_calendar/actions/workflows/ci.yml/badge.svg)](https://github.com/DevelopersCoffee/airo_calendar/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Cross-platform Flutter calendar capability wrapper with native OS integrations (Android, iOS, macOS), in-memory testing fakes, and diagnostic reporting — built for the [Airo](https://github.com/DevelopersCoffee) ecosystem.

---

## Features

* **Native Calendar Bridge**: Unified Dart API over Android, iOS, and macOS system calendars.
* **InMemory Test Fake**: `InMemoryCalendarService` for zero-side-effect unit testing.
* **Diagnostic Harness**: Built-in calendar diagnostic reporting and error isolation.

---

## Installation

```yaml
dependencies:
  airo_calendar: ^1.0.0
```
